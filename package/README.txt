MonitorAlign
============
Makes the mouse cross between monitors of different physical sizes at the same
physical height. Windows 10/11, no admin rights needed.

Install
  1. Unzip this folder anywhere.
  2. Double-click Install.bat.
     - Copies the app to %LOCALAPPDATA%\Programs\MonitorAlign
     - Adds a Start menu shortcut and starts it with Windows
     - Starts it now (look for the icon in the system tray)

Set it up
  1. Double-click the tray icon.
  2. Type each monitor's diagonal size in inches.
  3. Tick "Show guide lines" and drag a monitor in the preview (or select it and
     use the arrow keys) until the lines run straight across the gap.
  4. Optional: click "Aligned wallpaper..." and pick a picture to span across
     your monitors so it lines up.
  Tip: in Windows Display settings, put the monitors level with each other so the
  mouse can cross anywhere along the edge.

Uninstall
  Double-click Uninstall.bat (in this folder, or in
  %LOCALAPPDATA%\Programs\MonitorAlign run Uninstall.ps1).
  Settings are stored in %APPDATA%\MonitorAlign\settings.txt.

If Windows SmartScreen warns about the app, choose "More info" -> "Run anyway"
(the app is not code-signed).
